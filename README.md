# Счётчик постов VK и локальный Bash-инструмент

VK Mini App принимает ссылку на сообщество и показывает количество записей на его стене. Мини-приложение ничего не изменяет и не удаляет.

## Установка

1. Загрузите `index.html` на любой HTTPS-хостинг.
2. В настройках мини-приложения VK с ID `54762487` укажите полный адрес `index.html` как URL приложения.
3. Откройте приложение из VK и нажмите «Предоставить доступ».
4. Подтвердите запрос VK, вставьте ссылку на сообщество и нажмите «Проверить количество постов».

Токен доступа выдаётся VK на время работы приложения и хранится только в памяти страницы. В исходном коде он не записывается и никуда не отправляется. API-запрос выполняется через официальный VK Bridge.

## Локальная демонстрация через Docker

После запуска Docker Desktop выполните в папке проекта:

```powershell
docker compose up --build -d
```

Откройте `http://localhost:18765`. Локальная страница демонстрирует интерфейс; запрос прав VK работает только при запуске из мини-приложения VK по HTTPS-адресу.

Остановить демонстрацию:

```powershell
docker compose down
```

## Ограничение Mini App

Метод `wall.delete` запрещён для Mini Apps, поэтому удаление вынесено в локальный Bash-скрипт с токеном приложения типа Standalone.

## Bash-скрипт для удаления

`clear-posts-vk.sh` работает локально и использует пользовательский токен, полученный официальным приложением VK типа **Standalone** с правом `wall`. Токен вводится скрыто, не записывается в файл и не должен публиковаться в GitHub.

Требуются Bash, `curl` и `jq`. Запуск из Git Bash, WSL или Linux:

```bash
bash clear-posts-vk.sh
```

Скрипт принимает ссылку на сообщество, сначала получает полный список постов и показывает их количество. Удаление начинается только после ввода подтверждения вида `УДАЛИТЬ 123456`.
