# Очистка стены VK

Мини-приложение для личного использования. Оно считает и удаляет **только записи стены** сообщества, где у открывшего приложение пользователя есть права.

## Установка

1. Загрузите `index.html` на любой HTTPS-хостинг.
2. В настройках мини-приложения VK с ID `54762487` укажите полный адрес `index.html` как URL приложения.
3. Откройте приложение из VK, укажите ID сообщества и нажмите «Проверить количество постов».
4. Проверьте число постов и нажмите «Удалить все найденные посты». VK запросит доступ, если он ещё не выдан.

Токен доступа выдаётся VK на время работы приложения и хранится только в памяти страницы. В исходном коде он не записывается и никуда не отправляется.

## Ограничение

VK API и права доступа могут отличаться по типу приложения. Если VK не выдаст право `wall` или вернёт ошибку доступа, не пытайтесь обходить ограничение: откройте настройки приложения в кабинете разработчика и проверьте его тип/разрешения либо используйте личный скрипт с официальным токеном.
