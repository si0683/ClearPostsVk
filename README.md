# Очистка стены VK

Мини-приложение для владельцев и администраторов сообществ. Оно считает и удаляет **только записи стены** в сообществах, которыми управляет открывший приложение пользователь.

## Установка

1. Загрузите `index.html` на любой HTTPS-хостинг.
2. В настройках мини-приложения VK с ID `54762487` укажите полный адрес `index.html` как URL приложения.
3. Откройте приложение из VK и нажмите «Предоставить доступ к стене и сообществам».
4. Подтвердите запрос VK, вставьте ссылку на сообщество и нажмите «Проверить количество постов».
5. Проверьте число постов и нажмите «Удалить все найденные посты».

Токен доступа выдаётся VK на время работы приложения и хранится только в памяти страницы. В исходном коде он не записывается и никуда не отправляется. API-запросы выполняются через официальный VK Bridge. Каждый пользователь может удалить посты только в сообществах, где у него есть соответствующие права.

## Локальная демонстрация через Docker

После запуска Docker Desktop выполните в папке проекта:

```powershell
docker compose up --build -d
```

Откройте `http://localhost:18765`. Локальная страница демонстрирует интерфейс; запрос прав VK работает только при запуске из мини-приложения VK по HTTPS-адресу.

Остановить демонстрацию:

```powershell
docker compose down
```

## Ограничение

VK API и права доступа могут отличаться по типу приложения. Если VK не выдаст право `wall` или вернёт ошибку доступа, не пытайтесь обходить ограничение: откройте настройки приложения в кабинете разработчика и проверьте его тип/разрешения либо используйте личный скрипт с официальным токеном.
